# Static Container Review

Complete this path only if Docker Desktop is unavailable. It carries the same container objectives as the live build path.

## Review prompts

1. Explain the difference between the image defined by `Dockerfile` and a running container.
2. Identify each Dockerfile instruction and explain what filesystem layers it creates or uses.
3. State the exact `docker build` command you would run and tag the image as `registry.example.local/gridpulse:1.0.0`.
4. State the exact `docker run` command you would use to execute tests with the named volume mounted.
5. Explain how Compose connects the service to its named volume and bridge network.
6. Explain when you would push the image to a registry and why the local evaluation does not require a push.
